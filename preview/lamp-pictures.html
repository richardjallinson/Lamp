Lamp · Bible Word Puzzle

Picture List

One painting per story, 149 in Bible order, Genesis to Revelation. Each card has the file name to save as and a full prompt you can copy. Finished pictures are marked done; the rest are to make, in batches of ten.

How to make each picture

  1. Start with Batch 0, the Noah test. If the ark and rainbow keep Picture A’s style, carry on with Batch 1.
  2. Upload Picture A (Creation) as the style reference every time. In Midjourney, add --ar 9:16 --style raw and Picture A as a style reference.
  3. Tap Copy prompt and paste it in. Make 2–4 versions and keep the one that best matches Picture A.
  4. Save it with the exact file name shown, then tap Mark made.
  5. Send each finished batch back to Claude to check, crop to 9:16 and compress to about 200 KB.

Ticks are saved in this browser only. Rules in every prompt: no text, no faces, people only small and from behind, calm dark bottom third.
